# 微信九宫格动态表情包

一个根据参考图片制作微信表情包的 Codex Skill。上传人物、宠物、卡通角色或物品图片，选择喜欢的类型后，生成与角色和文案相匹配的九款表情。

## 功能

- 提供日常、情绪、搞笑、职场、校园、恋爱、亲子、宠物、吃喝、群聊、节日和长辈问候 12 个类型，每类附 9 条候选文案，也支持自定义。
- 根据文案设计角色动作、表情和文字的出现方式，保持角色形象一致。
- 默认制作 9 个独立循环 GIF 和 3 × 3 动态总览；也可按要求只输出静态图或提示词。
- 根据当前工具能力生成或合成动画，并检查文字、裁切和循环衔接；能力不足时如实说明未完成的部分。

## 使用

将本仓库放入 Codex 技能目录：

```bash
git clone https://github.com/ban-ge/wechat-sticker-pack.git ~/.codex/skills/wechat-sticker-pack
```

在支持技能的 Codex 会话中，上传参考图片并提出制作表情包的需求，也可以直接调用 `$wechat-sticker-pack`。尚未选择类型时，技能会展示类型和候选文案并等待选择；如已指定类型或文案，则按要求继续。

生成图片和 GIF 需要会话中具备相应的图像生成与动画制作能力。技能本身不包含生图模型或托管服务，也不会自动发布到微信表情平台。

## 文件

- `SKILL.md`：技能入口和制作流程。
- `references/categories.md`：类型列表及每类九条候选文案。
